# Security policy

## Supported versions

tiergraph is currently an alpha, pre-1.0 library. Security fixes are made on
`main` and, when a 0.1.x release is available, in the latest 0.1.x release. Older
pre-1.0 releases are not supported unless a maintainer states otherwise.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could put users at
risk.

Use GitHub's private vulnerability reporting for this repository, if it is
enabled, or contact:

`<maintainer security contact — to be filled by the maintainer>`

If neither private channel is available, use the repository issue tracker to
ask for a private reporting channel without including exploit details or other
sensitive information. The issue tracker is also appropriate for security
hardening suggestions that do not disclose an exploitable vulnerability.

Include the affected version or commit, impact, reproduction steps, and any
suggested mitigation you can safely provide. A maintainer will assess the report
and coordinate any fix and disclosure; this project does not promise a specific
response or release timeline.
