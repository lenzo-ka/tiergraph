# Salted SHA-256 digests of the repository names the publishability gate refuses
# anywhere in the shipped surface. The names are not written down here, or
# anywhere else in this repository: a digest is not a name, so the rule that
# nothing here may name them is not broken by the file that enforces it.
#
# The salt is tracked, because the gate has to reproduce these digests in CI
# from a clean checkout. That is a deliberate trade and it is worth stating
# plainly: this is not secrecy. A reader holding this file can confirm any name
# they already guess in milliseconds, and a short lowercase name falls to an
# ordinary dictionary sweep. What the salt buys is that no precomputed table
# answers the question for free. What the hashing buys is the property actually
# required -- that no forbidden name appears in a tracked artifact.
#
# Format: one `salt` line of hex, then one lowercase 64-hex digest per line,
# unique and sorted. Comments and blank lines are ignored. A missing, empty, or
# malformed file fails the gate closed. RELEASING.md records how to add an entry
# without writing the name into any file.
